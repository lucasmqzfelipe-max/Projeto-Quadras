# Verificação visual final

A página principal foi verificada em viewport desktop e mobile. O layout responsivo mantém a navegação, o hero, a busca, os filtros, o estado vazio, a faixa da comunidade e os passos de uso. O estado vazio é exibido corretamente quando não existem quadras cadastradas. O componente de mapa possui fallback visual e informa quando o serviço externo de mapas não está disponível; quando carregado, recebe os marcadores geocodificados das quadras filtradas.
